Questions

The code is not coming. What should I do?

Check that the number starts with the country code and has only digits, no + or spaces. Wait for the 30-second timer, then try again.

It says “already connected” or “reconnecting”.

This number already has a session with the bot. Wait a minute while it comes back online. If it still does not work, tap Get a new code to clear the old session and link again.

WhatsApp says the code is wrong.

Codes expire quickly. Generate a fresh code and type it within a minute. Make sure you chose Link with phone number instead, not the QR option.

Do I need to keep my phone online?

No. The bot runs as a linked device on the server, so it keeps working when your phone is off.

How do I remove the bot from my WhatsApp?

Open WhatsApp, Settings, Linked devices, tap the bot’s device and choose Log out.
